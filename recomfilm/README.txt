Projet: Générateur de Quiz Intelligent (Flask + API Groq)

1) Installation
- Créer et activer un environnement virtuel Python.
- Installer les dépendances:
  pip install -r requirements.txt

2) Configuration de la clé API Groq
- Ne pas mettre la clé dans le code.
- Définir la variable d'environnement GROQ_API_KEY.

Sous Linux/macOS:
  export GROQ_API_KEY="votre_cle_api"

Sous Windows PowerShell:
  setx GROQ_API_KEY "votre_cle_api"

3) Lancement
- Exécuter:
  python app.py
- Ouvrir ensuite l'application sur:
  http://127.0.0.1:5000

4) Structure attendue pour le rendu
- app.py
- templates/
- requirements.txt
- README.txt
- capture d'écran de l'application
